# Common English words, for machines with no system dictionary.
#
# jargon.py prefers /usr/share/dict/words and unions this in. Without either, every capitalised
# English word — THE, WAS, WITH — is reported as unexplained jargon, which is silent degradation into
# noise. Many Linux containers have no dictionary installed, so this is the floor.
#
# Closed-class words first, because those are the ones that appear in shouty prose and headings.
