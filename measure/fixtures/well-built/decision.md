We are going with the managed queue rather than running our own. Two reasons, and the second is the one
that decided it.

It costs about the same at our volume once you count the machines we would need. And nobody on the team
has operated this software before, so the first outage would be a first outage in every sense.

The trade we are accepting is that the managed version lags the open-source release by a few months. If
we need a feature before then we will have to wait for it.
