# The same message, before and after a person edited it

`agent-written.txt` is what an agent posted to a team chat channel. `human-edited.txt` is the same
change described by a senior engineer the same day, for the same readers. Nothing else differs: same
facts, same audience, same day.

The pair exists because the alternative is judging a rewrite against taste. These two are a real
before and after, so a check that cannot tell them apart is not measuring what it claims to.

Kept because a colleague's own writing is the only ground truth available for "well written for this
team". Neither file contains anything about a client or a person.
